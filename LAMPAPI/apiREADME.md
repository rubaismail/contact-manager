# LAMP API 

PHP API for the COP 4331C Contact Manager small project.

# Planned endpoints : 

- Login 
- Register
- AddContact
- DeleteContact
- UpdateContact
- SearchContact

# API Requirements 

- Receive JSON requests from the frontend
- Return JSON responses to the frontend
- Connect to the remote MySQL database 
- Implement server-side contact searching 
- Use prepared SQL statements for database queries 

# API Structure 

API configuration and shared functionality will be separated from individual endpoint files. 

# Responsibilities 

- Implementing PHP API endpoints 
- Handling JSON requests and responses 
- Connecting the API to the MySQL database 
- Validating API requests 
- Enforcing user/contact ownership 
- Implementing server-side contact search 
- Testing API endpoints 
- Documenting endpoints with SwaggerHub
